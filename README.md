# CUNUMA

Öffentliche Website der Premium-Marke CUNUMA für Carbon-Laufräder (Road und Gravel).

Die Anwendung läuft mit TanStack Start, React, TypeScript und Tailwind CSS. Next.js ist in dieser Veröffentlichung nicht im Einsatz: Build und Hosting sind auf TanStack Start ausgelegt. Inhalt, Seiten und Funktionen entsprechen dem Markenauftrag.

## Lokal starten

```bash
npm install
npm run dev
```

Die Entwicklungsumgebung horcht auf Port 8080.

```bash
npm run typecheck
npm run build
```

## Seiten

- Start, Road, Gravel, Produktdetails
- Technologie, Über CUNUMA, Kontakt, FAQ
- Impressum und Datenschutz (mit Platzhaltern, rechtlich zu prüfen)
- Konfigurator und Anfrageliste
- Checkout ohne Zahlung

## Ehrliche Grenzen

Maße, Gewichte, Naben, Speichen, Zertifikate und Firmendaten sind Platzhalter, solange sie nicht bestätigt sind. Das Kontaktformular sendet nichts an einen Server. Es gibt keine simulierte Zahlung.

## Veröffentlichung

Firmendaten, eine echte Kontaktadresse und ein Zahlungsanbieter werden eingesetzt, bevor ein Shop öffnet. Hosting-Anbieter, E-Mail-Dienst und Analyse bleiben in der Datenschutzerklärung als Platzhalter, bis sie feststehen.
